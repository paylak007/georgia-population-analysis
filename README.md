# Georgia Population Analysis (1994–2026)

A data analysis project exploring population trends across Georgia's regions and self-governed units from 1994 to 2026, using official data from the National Statistics Office of Georgia (Geostat).

## Project Overview

This project analyzes 32 years of population data to identify growth and decline patterns across Georgia's regions, municipalities, and cities.

## Tools Used
- Python
- Pandas (data cleaning & analysis)
- Matplotlib (data visualization)
- Jupyter Notebook

## Data Source
[National Statistics Office of Georgia (Geostat)](https://www.geostat.ge) — Population by regions and self-governed units, as of 1 January.

## Key Findings

- **Tbilisi** grew from 1,250.7K (1994) to 1,369.4K (2026), a **+9.5%** increase.
- **Batumi** showed the strongest growth at **+67.2%**, reflecting rapid urbanization on the Black Sea coast.
- Several rural municipalities experienced sharp population decline, with **Tsalka** (-63.7%), **Oni** (-62.7%), and **Tqibuli** (-56.7%) among the hardest hit — likely driven by migration to urban centers.
- The data reveals a clear urbanization trend: major cities (Tbilisi, Batumi) are growing while smaller rural municipalities are shrinking significantly.
